# Seoji-portfolio — 투자 판단 보조

판단 기준 명세([`docs/spec.md`](docs/spec.md))의 1차 구현. 스프레드시트가 종목 점수, 거름망, 시장 심리, 손실 한도, 매도 판단, 매수 이유 점검을 계산해 **제안**한다. 매매는 사람이 승인하고 직접 한다.

## 파일

| 파일 | 내용 |
|---|---|
| [`sheets/투자판단.xlsx`](sheets/투자판단.xlsx) | 빈 양식. 실제로 쓰는 파일 |
| [`sheets/투자판단_예시.xlsx`](sheets/투자판단_예시.xlsx) | 가상 데이터로 채운 예시. 숫자는 모두 지어낸 값 |
| [`docs/spec.md`](docs/spec.md) | 판단 기준 명세(확정) |
| [`docs/decisions.md`](docs/decisions.md) | 명세가 구현하는 쪽에 맡긴 것(자료 주기, 예외 처리, 기록 형식, 화면)을 정한 내용 |

## 쓰는 법

1. 구글 드라이브에 `.xlsx`를 올리고 **구글 시트로 열기**(또는 엑셀로 연다). 미리보기 화면에서는 계산 결과가 비어 보일 수 있다.
2. `안내` 탭의 순서대로 노란 칸에 자료를 넣는다.
3. `대시보드`에서 시장 심리, 보유 종목 제안(우선순위 ①~④), 편입 후보, 거시 패널을 본다.

| 탭 | 하는 일 (명세 번호) |
|---|---|
| 종목_한국 / 종목_미국 | 거름망(2), 지표 4개와 점수(1), 판정(편입 후보·교체 제안), 점수 설명 카드 |
| 보유 | 손실 한도(5), 매도 판단 우선순위(6) |
| 매수이유 | 이유 1~3개, 핵심 1개, 근거·무너짐 기준, 점검 결과(7) |
| 매수계획 | 시장 심리에 따른 분할 매수 횟수·간격·금액·날짜(3) |
| 판단기록 | 제안과 내 결정을 남기는 기록 |
| 심리_미국 / 심리_한국 | 시장 심리 지수 계산과 지표별 설명(3) |
| 거시 | 거시 참고 패널, 표시만(4) |
| 자료_* | 원자료 붙여 넣는 곳 |
| 설정 | 판단 기준 값 |

## 개발

시트는 손으로 고치지 않고 코드로 다시 만든다.

```bash
pip install openpyxl pytest
python -m builder        # sheets/ 두 파일을 다시 만든다
python -m pytest         # LibreOffice(soffice)가 있으면 시트 수식까지 대조
```

| 폴더 | 내용 |
|---|---|
| `judge/` | 판단 기준의 파이썬 구현. 시트 검증의 기준이고 2차(파이썬) 구현의 출발점 |
| `builder/` | 시트 생성(`workbook.py`)과 예시용 가상 데이터(`example.py`) |
| `tests/` | 손으로 계산한 값과의 대조(`test_rules.py`), 시트 수식과 파이썬 구현의 칸별 대조(`test_workbook.py`) |

판단 기준 값은 `judge/common.py`에만 있다. 시트의 `설정` 탭도 이 값으로 만든다.
